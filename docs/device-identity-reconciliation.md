# Сверка отправленных и обнаруженных USB-устройств

## Идентификатор кампании

`usb-gadget-campaign.py` резервирует строковый USB-дескриптор `iSerialNumber` для уникального ID каждого case:

`URTK-<campaign_id>-<case>`

Пример: `URTK-91A2B3C4D5-00017`.

ID записывается в JSON-профиль до запуска Raw Gadget, а также в `manifest.json`, `campaign.jsonl` и `summary.json`. Поле `iSerialNumber` указывает на строковый дескриптор, а не содержит сам текст серийного номера.

## Что извлекается из USBPcap

Анализатор просматривает весь PCAPNG, а не только временные окна cases:

1. `GET_DESCRIPTOR(Device)` — VID/PID и индекс `iSerialNumber`.
2. `GET_DESCRIPTOR(String)` с индексом `iSerialNumber` — фактический текст серийного номера.
3. `SET_ADDRESS` — связывает первоначальный Device Descriptor, полученный на адресе 0, с последующими запросами по назначенному адресу.
4. `SET_CONFIGURATION` — подтверждает, что хост активировал конфигурацию. Одного успешного GET_DESCRIPTOR недостаточно, чтобы утверждать, что устройство установлено.

## Статусы сверки

- `RECEIVED_AND_CONFIGURED` — серийный номер считан, `SET_CONFIGURATION` завершился.
- `RECEIVED_ENUMERATION_INCOMPLETE` — серийный номер считан, но завершение конфигурации не подтверждено.
- `RECEIVED_CONFIGURED_SERIAL_NOT_READ` — Device Descriptor и SET_CONFIGURATION наблюдались, но хост не запросил строку серийного номера; применено ограниченное сопоставление по времени последовательной кампании.
- `DEVICE_DESCRIPTOR_SEEN_SERIAL_NOT_READ` — Device Descriptor замечен, но конфигурация не подтверждена и строка серийного номера не считана.
- `NOT_OBSERVED_IN_PCAP` — для case не найдено соответствующей host-сессии.
- `AMBIGUOUS_MULTIPLE_HOST_SESSIONS` — временная корреляция не уникальна.

## Ограничения интерпретации

`NOT_OBSERVED_IN_PCAP` не доказывает, что устройство заблокировал фильтр. Хост может не запрашивать строковый дескриптор, PCAPNG может быть снят не с того Root Hub, захват может пропустить начало enumeration, а часы Pi и Windows могут расходиться. Для временного сопоставления используется `--host-clock-offset-seconds` и допуск `--time-tolerance`.

Серийный номер — идентификатор в USB-дескрипторе, а не криптографическая аутентификация. Фильтр может блокировать именно запрос строкового дескриптора или устройство до того, как хост прочитает серийный номер. Поэтому в отчёте отдельно показываются факт наблюдения Device Descriptor, факт чтения серийника и факт `SET_CONFIGURATION`.
